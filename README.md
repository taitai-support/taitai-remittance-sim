# 送金シミュレーション（公開用フォルダ）

お客様向け「送金シミュレーション」の公開ファイル一式です。

## 置き場の設計（標準の形）

- コードの正本：GitHub リポジトリ（新規 `taitai-remittance-sim` を想定）にこのフォルダの中身を置く
- 公開：GitHub Pages ＋ 独自ドメインの固定アドレス
  - 候補：`https://sim.taitai-support.com/`（サブドメイン方式。作り直してもこのURLは変わらない）
  - 公式LINEのリッチメニュー／案内文にはこの固定URLだけを貼る
- 実際の公開（リポジトリ作成・Pages有効化・ドメイン設定）は、タイタイの最終確認後に行う

## ファイル

- `index.html` … 本体（単一ファイル。画像・動画・スタイル・計算をすべて内包）
- `rate.json` … レート連動用。本体はこのファイルを読み、`rate` と `date` がそろっている時だけ本物のレートとして表示する。読めない時はサンプルレート表示に切り替わる

## レートの運用

- 平日11:30頃（本家の当日レート確定＝10:30の約1時間後）に、本家のレートを確認して `rate.json` の `rate` と `date` を更新し、GitHubへ反映する
- 銀行休業日・緊急のお知らせは、本体HTML内の `NOTICES` 配列に1行足す（表示はページ上部）
- 前日のレートを使い回さない（`date` が当日の物だけを本物として扱う設計）
